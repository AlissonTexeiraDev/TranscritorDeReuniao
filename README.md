# Transcritor de Reunião

Tomador de notas de reunião para Windows que roda como servidor **MCP** local: captura o áudio da
reunião (caixas + microfone), transcreve com Whisper localmente e entrega a transcrição em tempo real
ao Claude Desktop ou ao Claude Code, que redige a ata.

O código está em [`MeetingNotesMcp/`](MeetingNotesMcp/). Instruções de compilação, configuração e
conexão com o Claude: [MeetingNotesMcp/README.md](MeetingNotesMcp/README.md).
